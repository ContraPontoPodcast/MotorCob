Perguntas frequentes

O que é o MotorCX?

Uma plataforma de inteligência de decisão para a experiência do cliente: decide quem contatar, por qual canal, em qual telefone, em que momento e o que cada resposta quer dizer. Ela aprende com o resultado de cada conversa.

MotorCob e MotorCli são produtos diferentes?

São frentes de atuação do MotorCX. A inteligência, a plataforma e a segurança são as mesmas; muda o momento da relação com o cliente. O MotorCob cuida da cobrança e o MotorCli, da jornada do cliente. Você liga as frentes que usa.

O MotorCX é uma ferramenta de disparo?

Não. Os disparos existem para executar as decisões, mas são opcionais: dá para usar só a inteligência com os canais que você já tem.

Preciso trocar meu discador ou meus fornecedores?

Não. A Lista do dia sai em arquivo por canal e pela API, e os retornos voltam por arquivo ou API, ensinando o MotorCX.

Como a IA trata os dados dos clientes?

Nenhuma IA recebe CPF, telefone ou e-mail: esses dados são apagados antes. As telas mostram só o ID do cliente.

Como é a contratação?

O MotorCX com as frentes que você usa, e os recursos de execução pelo uso. Fale com o time para uma proposta.
