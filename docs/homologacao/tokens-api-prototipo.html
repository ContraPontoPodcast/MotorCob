Primeira chamada

curl -X POST "https://api.motorcob.online/v1/cargas?credor=banco-alfa&tipo=incremental&nome=incremental.csv" \
  -H "Authorization: Bearer mc_1a2b…" -H "Content-Type: text/csv" \

Confere o token e o que ele pode, sem enviar nada.
Regras
  • "Testar agora" chama GET /v1/teste com o token: responde quem é a empresa, o que o token pode e as carteiras — sem mexer em nada.
  • O exemplo já vem com o código da carteira escolhida.
  • O endereço da API passa a ser api.motorcob.online (hoje aparece o endereço técnico do Supabase).

Trocar token · ERP Financeiro

Cria um novo com as mesmas permissões; o antigo continua valendo por alguns dias para dar tempo de colar o novo no sistema.

Mesmo nome, permissões, carteiras e IPs. Validade nova: 90 dias.

Depois de colar o novo, veja em Uso e erros se o antigo parou de ser chamado e use "Parar agora". No fim do prazo ele para sozinho e o sino avisa se ainda estava sendo usado.
